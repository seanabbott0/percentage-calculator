# Percentage Calculator

A mathematical tool for common percentage calculations.

## Features

- Percentage of a number
- Percentage ratio
- Percentage change

## How to Use

Select a calculation type and enter two values.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
